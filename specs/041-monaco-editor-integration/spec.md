# 功能规范：Monaco Editor 代码编辑器集成 (Spec)

## 1. 概述与设计理念

UniRTM 致力于打造轻量、纯净、符合安全与敏捷规范的 Web 版开发者工作台。在已完成 VS Code 风格资源管理器（File Explorer）的基础之上，本规范定义核心编辑体验——**Monaco Editor 代码编辑器深度集成**。

### 核心设计原则
1. **完整功能不裁剪**：遵循用户明确指令，不剔除语法高亮、智能补全、括号匹配、代码折叠、小地图（Minimap）、查找替换等 Monaco 原生核心能力。
2. **100% 离线与按需异步懒加载**：Monaco Editor 资源完整打入项目本地生产包，但在应用首次打开时**不阻断首屏**，仅当用户进入资源管理器并首次打开代码文件时通过 Vite 异步分包 (`dynamic import`) 触发加载，兼顾秒开性能与全功能体验。
3. **多标签页 (Tabs) 工作区管理**：对标 VS Code 编辑器顶部 Tab 交互，支持多文件同时打开、标签平滑切换、未保存脏标记 (`●`)、快捷关闭与溢出滚动。
4. **主题与设计系统原生融合**：Monaco 主题深度响应 UniRTM 现有主题系统（深色模式、浅色模式与 Open VSX 导入主题），状态栏与键帽风格保持一致。
5. **文件系统双向闭环**：通过 `/api/fs/read` 与 `/api/fs/write` 实现高可靠读写保存与快捷键 `Ctrl+S`。

## 2. 用户故事与使用场景

- **场景 1：多文件浏览与编辑**：
  用户在左侧资源管理器中依次点击 `cmd/main.go`、`frontend/src/App.vue` 和 `README.md`，顶部 Tab 栏依次呈现 3 个文件标签，用户点击 Tab 可瞬时切换不同文件模型，编辑内容互不干扰。
- **场景 2：代码修改与快捷保存**：
  用户修改代码，对应 Tab 显示脏标记圆点 `●`；按下 `Ctrl+S`（或点击保存按钮），自动调用安全写接口保存至磁盘，脏标记自动清除并弹出成功轻提示。
- **场景 3：语法提示与辅助开发**：
  用户编写 Go、TypeScript、Python、JSON 或 TOML 时，Monaco 自动识别语言类型并提供精准语法高亮、缩进指引、代码折叠、小地图与补全提示。
- **场景 4：非文本文件优雅适配**：
  若用户选择 PNG/SVG/JPG 等图片，编辑器自动切换为带棋盘格透明背景的图像预览视图；若为未知二进制，友好提示大小并提供十六进制或外部工具操作指引。

## 3. 功能详细规格

### 3.1 异步动态加载引擎
- 采用 `monaco-editor` 核心包，配置 Vite 构建器自动分割独立的 Monaco Worker 和代码 Chunk。
- 加载过程呈现轻量极简骨架指示器 (`codicon-loading`)，加载完成后自动无缝挂载。

### 3.2 多标签页 (Editor Tabs)
- **Tab 属性**：路径 `path`、文件名 `name`、语言 `language`、是否修改 `isDirty`、滚动位置与光标状态记忆。
- **快捷动作**：
  - 单击激活 Tab；
  - 点击关闭按钮 `✕` 关闭单页（若有未保存更改可提示确认）；
  - 中键单击快速关闭 Tab；
  - 快捷保存当前 Tab (`Ctrl+S`)；
  - 关闭全部 / 关闭其他 Tab。

### 3.3 语言自动推导矩阵
覆盖 UniRTM 及日常开发的核心语言与配置文件：
- `.go` -> `go`
- `.ts`, `.tsx` -> `typescript`
- `.js`, `.jsx`, `.mjs`, `.cjs` -> `javascript`
- `.vue` -> `html` (或 vue 模式)
- `.py` -> `python`
- `.rs` -> `rust`
- `.json` -> `json`
- `.toml` -> `ini` / `toml`
- `.yaml`, `.yml` -> `yaml`
- `.md` -> `markdown`
- `.sh`, `.bash`, `.zsh` -> `shell`
- `.bat`, `.cmd` -> `bat`
- `.ps1` -> `powershell`
- `.css`, `.scss`, `.less` -> `css`
- `.html`, `.htm` -> `html`
- `.sql` -> `sql`
- `Dockerfile` -> `dockerfile`

### 3.4 编辑器底部状态栏增强
- 光标行号与列号（如 `行 42, 列 18`）；
- 编码格式（`UTF-8`）；
- 换行符（`LF` / `CRLF`）；
- 当前语言模式名称（点击可展示语言标识）；
- 文件尺寸与只读/可写指示。

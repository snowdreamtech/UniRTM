# 规范文档：工具链状态清晰化与低噪音升级标识优化系统 (Specification)

## 1. 业务背景与问题分析 (Problem Statement)

在现代开发环境与工作区工具链管理中，存在两个本质不同的维度：
1. **声明式配置 (Desired State / Configuration)**：当前工作区（如 `.mise.toml` 或 `.tool-versions`）声明了需要的版本（例如 `node = "20.18.3"`）；
2. **本地物理安装 (Actual State / Installation)**：本地磁盘中真实下载并就绪了该版本的可执行文件。

### 当前界面存在的核心缺陷：
- **状态混淆与假象**：当前只要配置了版本（`active_version` 或 `global_version`），界面就直接打上绿色亮底的徽章。若开发者刚克隆仓库且尚未执行安装，界面依然显示高亮版本号，给用户“工具已就绪”的错觉，实际运行却报 `command not found`。
- **色彩语义滥用与冲突**：绿色（`#10b981` / `--success`）被广泛分配给所有已配置的工具，导致当工具真正检测出“有新版本可升级”时，升级提示无法脱颖而出。
- **视觉噪音过高**：如果对每个正常就绪的工具都打上“已安装”图标或重复标记，全屏充斥着冗余元素。

## 2. 设计哲学与核心原则 (Design Principles)

1. **异常驱动（Design by Exception）**：
   - 绝大多数工具在正常就绪时应当保持**沉稳、极简、无噪音**的中性质感；
   - **已安装且就绪的工具不展示多余图标**，仅呈现版本文本；
2. **绿色专属留给升级（Green Reserved for Upgrade）**：
   - 绿色（`--success`）专属指代“有更新可用（Upgradable）”，让升级机会在整个工具链面板中一目了然；
3. **精准提示缺失（Explicit Missing Alert）**：
   - 当检测到工作区配置了某版本但本地磁盘尚未安装时，明确标识为“待安装 / 缺失”，并自适应提供一键安装动作。

---

## 3. 工具状态四象限规范 (State Matrix)

| 状态标识 | 业务条件 | 视觉样式表现 | 操作按钮自适应 |
| :--- | :--- | :--- | :--- |
| **就绪 (Ready)** | 工作区已配置且本地已安装版本 A | • 沉稳中性色徽章（深色主题浅灰底白字，浅色主题柔灰底深字）<br>• **不展示任何额外图标或文字标签** | `[切换版本]` + `[更多]` |
| **可升级 (Upgradable)** | 本地检测到更高版本或远程有新版本可用 | • 版本号旁展示**专属绿色高亮胶囊**（如 `↑ 可升级`）<br>• 绿色圆点或文字提示 | `[一键升级]` / `[切换]` |
| **缺失 (Missing)** | 工作区已配置版本 A，但本地未安装该版本 | • **琥珀色/警示色徽章**（如 `v20.18.3 需安装`）<br>• 明确提示磁盘尚未下载 | 主按钮直接变为高亮醒目的 `[立即安装此版本]` |
| **未配置 (Unconfigured)** | 工作区未配置任何版本 | • 弱化灰色徽章展示 `未配置` | `[安装]` / `[配置]` |

---

## 4. 交互与功能规范 (Functional Requirements)

1. **状态计算器 (`getToolStatus(rt)`)**：
   - 统一抽象状态计算逻辑，返回 `{ state: 'ready' | 'upgradable' | 'missing' | 'unconfigured', activeVer, upgradableVer }`；
2. **卡片视图（Grid View）与表格视图（Table View）全量对齐**：
   - 网格卡片右上角与表格中版本列均应用同一套色彩与图标策略；
3. **主操作按键自适应联动**：
   - 当状态为 `missing` 时，卡片首要动作变更为直接触发安装该特定版本；
4. **53 种国际化多语言支持**：
   - 包含新增状态文案（如 `runtimes.status_missing`、`runtimes.status_upgradable` 等）在 53 种语言中的精确无缝翻译。
5. **顶部搜索工具栏缺失统计与快捷筛选 (Toolbar Missing Counter & Quick Filter)**：
   - 在搜索栏右侧统计徽标区，当 `scopeMissingCount > 0` 时，动态展示琥珀色 `⚠️ N 个待安装` 徽标；
   - 支持点击徽标一键切换“仅看待安装”与“看全部”，极速聚焦需下载补齐的环境；
   - 当待安装数为 0 时，静默不展示，严格贯彻低噪音设计原则。

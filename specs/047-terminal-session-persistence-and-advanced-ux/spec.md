# 功能规范：集成终端会话持久化、动态状态感知与高级体验系统 (Spec)

## 1. 概述与背景
集成终端是现代云原生及专业 IDE（如 VS Code、Cursor、Zed）中生命周期最长、使用频率最高的交互界面之一。
在完成了 `046` 交互增强（超链接跳转、全文搜索、上下文菜单、代码流转）之后，随着用户在复杂项目构建、微服务并发启动与长期测试中的重度依赖，终端暴露出以下更深层次的体验痛点：
1. **刷新与切换视图导致日志丢失**：当用户刷新浏览器、重新加载页面或因网络抖动触发 WebSocket 重连时，现有终端历史缓冲区被重置清空，耗时较长的长任务构建日志与关键错误记录不复存在；
2. **多终端 Tab 辨识度低下与静态标签僵化**：多个终端实例全部显示为相同的静态 shell 名称（如 `bash`、`zsh`），用户无法一目了然区分哪个窗口正在运行 `npm run dev`、哪个正在运行 `go test`、哪个在执行后台数据库，容易误杀关键进程；
3. **长任务缺乏后台感知与退出反馈**：编译、依赖安装或端到端测试耗时长达数分钟，用户切换到其他编辑器 Tab 时必须频繁切换视口盯屏，任务执行完毕（或突发报错中断）缺乏及时的上下文 Toast 与声音/视觉通知；
4. **日志排查缺乏导出留存工具**：排查生产问题或向团队提报 Bug 时，缺乏一键将终端当前缓冲区导出为标准文本/日志文件的快捷途径；
5. **图形渲染与代码连字审美不足**：在大批量高频吞吐日志输出时缺少硬件加速平滑机制，缺乏现代开发者推崇的编程连字字体（Ligatures）视觉增强。

本特性旨在彻底解决上述痛点，构建具备会话历史无缝恢复、动态子进程感知、后台长任务智能通知、日志导出与硬件渲染增强的下一代专业终端交互矩阵。

## 2. 核心用户故事 (User Stories)

### 故事 1：会话日志持久化与刷新平滑恢复 (Session Buffer Persistence)
- **作为** 一名正在运行长耗时构建或持续查看日志的开发者，
- **我希望** 在不小心刷新浏览器或断网重连后，终端能够自动回放重连前的历史滚动缓冲区与输入状态，
- **以便于** 我无需重新执行漫长的构建流程即可完整查阅先前的输出记录。

### 故事 2：前台子进程智能识别与动态 Tab 徽标 (Dynamic Process-Aware Tabs)
- **作为** 一名并发管理多个终端会话的工程师，
- **我希望** 终端 Tab 标题根据当前前台运行的实际程序（如 `node`、`python`、`go`、`cargo`、`docker` 等）动态变换，并展示对应的技术栈小图标，
- **以便于** 我在多个终端标签页之间秒级精准识别各终端当前执行的工作负载。

### 故事 3：长耗时后台任务完成通知与退出码感知 (Long-Running Task Completion Alert)
- **作为** 一名专注于主编辑器编写代码的工程师，
- **我希望** 当终端在后台执行任务（>10秒）结束或发生非 0 异常退出时，系统能自动弹出带有状态与耗时的通知气泡，
- **以便于** 我无需反复切屏盯看进度，并在任务失败时第一时间感知并快速排查。

### 故事 4：终端日志一键导出与留存 (Export Terminal Output)
- **作为** 一名排查疑难杂症或提报 Issue 的测试人员或开发者，
- **我希望** 在终端右键菜单或工具栏上一键点击「导出终端日志 (Export Log)」，
- **以便于** 将当前会话的全部输出保存为带时间戳的 `.log` 文件用于离线分析。

### 故事 5：WebGL 硬件加速与代码连字渲染 (WebGL & Font Ligatures)
- **作为** 一名追求极致流畅度与专业审美的开发者，
- **我希望** 终端具备 GPU 硬件加速渲染，并支持现代等宽字体连字效果（如 `=>`, `!==`, `->`），
- **以便于** 在面对海量吞吐日志时终端依然保持 60fps 丝滑流畅，并获得赏心悦目的视觉观感。

## 3. 验收标准 (Acceptance Criteria)

1. **会话缓存持久化与重放**：
   - 前端维护按 `paneId` 隔离的 Ring Buffer 滚动历史缓存（支持最大 5,000 行记录，支持会话存储与内存级高速恢复）；
   - 终端重新连接或刷新页面后，自动恢复历史日志文本，无闪烁与乱码；
   - 提供「清空历史缓存 (Clear Persistent Buffer)」与「导出完整日志 (Export Terminal Log)」能力。
2. **动态进程感知与自定义标签**：
   - 能够从终端输出流中嗅探当前运行的前台主任务特征（如 Node/Vite/Python/Go/Cargo/Docker/Git 等），实时将 Tab 名称更新为对应进程名；
   - 针对不同进程类型渲染对应技术栈图标与状态色；
   - Tab 支持自定义重命名与双击就地编辑。
3. **后台任务监控与完成通知**：
   - 记录命令开始执行时间戳；当执行耗时超过 10 秒且终端处于后台（非活跃 Tab 或抽屉折叠）时，命令执行结束自动触发系统 Toast 提示；
   - 识别命令执行成功（0）与失败（非 0），并在通知和 Tab 标题上直观区分。
4. **WebGL 加速与连字视觉**：
   - 支持引入 `@xterm/addon-webgl` 进行硬件加速，若运行环境或浏览器不支持 WebGL 时自动无感降级；
   - 支持代码连字符（Ligatures）平滑显示。
5. **多语言与质量保证**：
   - 新增所有 UI 词条与提示完全适配系统支持的 53 种国际化语言；
   - 单元测试覆盖率达到 100%，全量测试全绿并通过生产打包。

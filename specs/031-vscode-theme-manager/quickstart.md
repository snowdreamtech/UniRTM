# Quickstart: VS Code Theme Package Management in UniRTM

## 1. Installing a Theme via GUI
1. Open UniRTM Workbench -> Settings -> Appearance.
2. Under "Theme Management", click "Install VS Code Theme (.vsix)".
3. Select any `.vsix` file downloaded from the VS Code Marketplace or Open VSX.
4. The theme will automatically install to `~/.local/share/unirtm/themes/` and appear in the theme selection dropdown.

## 2. Installing Manually via Local Folder
You can also directly drop any unzipped VS Code theme directory into:
- Color themes: `~/.local/share/unirtm/themes/colors/<theme-name>/`
- Icon themes: `~/.local/share/unirtm/themes/icons/<theme-name>/`

Then click "Refresh Themes" or reload the page.

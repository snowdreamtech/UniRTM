# 功能规范：集成终端深度交互与工作区协同增强系统 (Spec)

## 1. 概述与背景
集成终端 (Integrated Terminal) 是现代专业级云原生与本地集成开发环境（IDE，如 VS Code）的核心基础设施之一。
在 UniRTM 中，终端虽然已经实现了基础的 WebSocket PTY 双工通讯、多 Tab/分屏布局以及端口嗅探转发，但在日常高频开发交互中仍存在以下断点与痛点：
1. **报错日志与文件跳转割裂**：编译错误、测试失败或运行堆栈中打印了诸如 `src/views/App.vue:42:15` 或 `main.go:88` 的路径时，用户无法直接点击跳转，只能手动切换到编辑器或文件树逐层寻找打开并定位行号；
2. **终端内部信息检索困难**：海量构建日志、微服务输出或长输出命令执行完毕后，缺乏像编辑器一样的内置搜索工具条，用户无法快速查找、定位关键词及正则匹配；
3. **右键操作缺乏标准上下文**：终端右键缺乏复制、粘贴、清屏、全选、拆分等上下文菜单支持，操作习惯与标准桌面/Web IDE 不一致；
4. **代码执行与终端流转断裂**：在编辑器中编写脚本、SQL、Python 或 Shell 代码时，缺乏一键将选中代码或当前行直接投递到活动终端执行的能力（`Shift+Enter`）；
5. **文件树与终端定位缺少桥梁**：在资源管理器中右键某个子目录或项目包时，无法一键在集成终端中以该目录为工作区打开或执行 `cd` 命令。

本特性的目标是彻底打通集成终端与编辑器、文件浏览器之间的交互壁垒，提供堆栈链接穿透、全文搜索、上下文菜单、代码流转执行以及目录即时呼起能力。

## 2. 核心用户故事 (User Stories)

### 故事 1：堆栈追踪与文件超链接穿透跳转 (File & Stack Trace Navigation)
- **作为** 一名进行代码调试或运行测试的工程师，
- **我希望** 终端中输出的编译报错、异常堆栈或文件路径（如 `src/App.vue:25:10`、`pkg/service/user.go:102`）能够自动识别为可点击链接，
- **以便于** 按住 `Ctrl` (或直接点击) 时能穿透直接在主编辑器中打开该文件并精准高亮定位到指定行与列。

### 故事 2：Web URL 自动识别与快速访问 (Web Link Detection)
- **作为** 一名启动本地 Dev Server 或查看工具文档的开发者，
- **我希望** 终端中打印的 `http://localhost:3000` 或外部文档链接能够自动高亮，
- **以便于** 点击后能在系统默认浏览器或新窗口中安全打开。

### 故事 3：终端内置浮动全文搜索 (Terminal In-Panel Search)
- **作为** 一名排查长日志与编译信息的开发者，
- **我希望** 在终端中按 `Ctrl+F` (或 `Cmd+F`) 时能呼出类似 VS Code 的右上角悬浮搜索工具条，
- **以便于** 我能够进行增量搜索、前后跳转匹配项、高亮匹配结果，并支持大小写匹配、全字匹配与正则搜索。

### 故事 4：终端全功能右键上下文菜单 (Terminal Context Menu)
- **作为** 一名习惯鼠标或键盘协同的高效开发者，
- **我希望** 在终端任何区域右键时能唤出与 IDE 主题高度融合的上下文菜单，
- **以便于** 快速执行「复制」、「粘贴」、「全选」、「清屏」、「查找」、「拆分终端」与「重启会话」。

### 故事 5：编辑器代码直发终端执行 (Send Selection/Line to Terminal)
- **作为** 一名编写脚本、SQL 或命令行的开发者，
- **我希望** 在编辑器中按 `Shift+Enter` 或右键选择「在活动终端中运行」，
- **以便于** 自动将当前选中的代码块（或当前光标所在行）无缝发送到当前活动终端中执行，若终端处于折叠状态则自动拉起展现。

### 故事 6：文件树目录直达终端 (Open in Integrated Terminal)
- **作为** 一名管理多模块或深层嵌套目录项目的工程师，
- **我希望** 在文件管理器中右键任意目录时能点击「在集成终端中打开」，
- **以便于** 终端自动定位或执行 `cd` 切换到该目录，免去手动输入长路径。

## 3. 验收标准 (Acceptance Criteria)

1. **堆栈超链接识别与跳转**：
   - 支持主流文件路径格式解析：包含相对路径、绝对路径、带行号（`:line`）及行列号（`:line:col`）等模式；
   - 鼠标悬停显示链接下划线与气泡提示，点击或快捷组合键触发全局 `workspaceBus.openInEditor`，并在编辑器中准确定位至对应行列；
   - URL 链接支持 `http://` 与 `https://` 协议，点击正常唤起外部打开。
2. **终端搜索工具条**：
   - 快捷键 `Ctrl+F` / `Cmd+F` 即可唤起/聚焦搜索浮窗；
   - 包含输入框、上一个 (Prev)、下一个 (Next)、关闭 (Close) 按钮；
   - 包含 Match Case (大小写)、Match Whole Word (全字匹配)、Use Regex (正则) 状态切换开关；
   - 搜索词实时高亮终端缓冲区中的匹配项，按 `Enter` 切换下一个，`Shift+Enter` 切换上一个，`Esc` 退出。
3. **右键上下文菜单**：
   - 右键精准阻止默认浏览器菜单并唤出自绘样式菜单；
   - 有文本选中时「复制」高亮可用，无选中时灰显；
   - 点击「粘贴」能顺利将剪贴板内容写入当前活动 PTY 流；
   - 提供「清空终端」、「全选」、「查找」、「拆分」等标准操作。
4. **编辑器到终端流转**：
   - Monaco 编辑器注册快捷键 `Shift+Enter`；
   - 优先发送选区内容；若无选区则自动提取光标所在整行内容并向后移动一行光标；
   - 若终端面板当前处于隐藏状态，自动展开底部面板并激活终端 Tab。
5. **资源管理器目录直达终端**：
   - 目录右键菜单包含「在集成终端中打开 (Open in Integrated Terminal)」；
   - 点击后将 `cd "<relativePath>"` 发送到当前活动终端执行。
6. **国际化与质量保障**：
   - 所有新增 UI 文案完整同步支持项目内置的 53 种语言包；
   - 新增单元测试与全量既有测试均通过，生产环境打包（`npm run build`）0 错误。
